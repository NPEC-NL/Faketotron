# Light Calibration Files

The csv files here is created by measuring the chamber's light by PSI's SpectraPen device, then calculate the linear regression parameters (A, b for slope and intercept) for every measurement points between wavelength 315-800 nm.

The r2 scores for linear regression are >0.95 in the effective wavelength range of the corresponding light type (e.g. 400-700 for Cool White LED panels). However, these files should be re-calibrated at least once a year.
