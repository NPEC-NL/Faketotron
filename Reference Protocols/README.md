# Reference Protocols

In this folder, you can find some previously used protocols for certain plant species.

File Naming:
- `LD/SD`: Long (16hr) or short (8hr) day.
- `_H/L`: High or low light intensity.
- `s1`,`t2`,`d5`: Which chamber and what type of chamber (standard, temperature, daylight) it was for.


## Good to know 

- We provided many protocols for a same type, since the light intensity setting could be (slightly) different between the chambers. You can use the Light Tools to see the estimated PAR level for an average chamber. You can let us know your desired PAR level and we will do a light intensity correction for your experiment.
- Sometimes, if the Standard or Temperature chambers are all occupied, we also use Daylight chamber to create the same conditions, and that's why you can see protocols under the same folder having `d-` in their file names.
- It is recommended to always add a half hour ramp phase to simulate gradual change between day and night.
